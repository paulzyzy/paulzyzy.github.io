# Yuan Zhuang Personal Website

Static GitHub Pages website for `https://paulzyzy.github.io/`.

The site is intentionally build-free. GitHub Pages can serve it directly from the repository root on the `main` branch.

## Updating the CV

Replace `assets/Yuan_Zhuang_CV.pdf` with the latest compiled CV. Keep this public
filename stable so previously shared links continue to work. The CV link in
`index.html` opens the PDF in a new tab, where visitors can view or download it.
Update its `?v=YYYYMMDD` version when replacing the PDF, then commit and push the
PDF and HTML together. The CV source is maintained separately in `../Yuan_CV/`.

## Preview

Open `index.html` directly in a browser. There are no dependencies or build steps.
